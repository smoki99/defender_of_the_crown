# SPEC: Defender of the Crown 2.0 — "The Crown Endures"

**Status:** DRAFT v2 — awaiting human approval (supersedes v1 draft)
**Repo:** `smoki99/defender_of_the_crown` · companion: `docs/CAPABILITY-MAP.md`

## 1. Objective

A browser-playable **retro-modern strategy game** that *feels* like a lost 1991
Deluxe version of the Amiga classic *Defender of the Crown* — same spirit,
same chunky pixel-and-chiptune soul, but a **version 2.0, not a replica**: a
deeper campaign, a motivating musical opening, and thirteen lovingly crafted
minigames that pull the player back "just one more turn".

The player commands the **Saxons**; the AI commands the **Normans**. Conquer
England castle by castle. Along the way: tournaments, sieges, duels, spies,
plagues, Danish raiders, and a dragon.

**Users:** desktop browsers first (mouse+keyboard), tap-friendly secondary.
**Success:** a player can open the page, hear a rousing title overture, choose
difficulty, play the full campaign loop, win minigames for real advantages,
and reach victory/defeat — all client-side, zero copyrighted assets.

### 1.1 Legal & creative ground rule (inviolable)

Original creation only, in the Amiga *visual/audio language*. No sprites, no
fonts, no illustrations, no music notes, no sampled audio from the 1989 game
or any other copyrighted work. Name in repo/title is a description of the
genre; the in-game title card reads **"The Crown Endures — A Saxon
Liberation"** with a subtitle "in the tradition of 16-bit castle strategy".
All art/music is generated by our own code and tools → provenance = this repo.

## 2. Presentation bible ("Amiga quality" made testable)

| Constraint | Value | Why |
|---|---|---|
| Internal resolution | **320×256** (Amiga PAL lo-res), integer scale ×3 → 960×768, `image-rendering: pixelated` | the chunky-pixel look is a law, not a filter |
| Color | **32-color indexed palette**, hand-picked Amiga hues; EHB-style half-bright done in code | authentic hue set; forces cohesive art |
| Shading | 3-tone material rule (dark/base/highlight), 1px dark outlines, **Bayer 4×4 ordered dither** for gradients | the era's entire shading vocabulary |
| Text | original hand-drawn **8×8 bitmap font** (Topaz-adjacent, our own glyphs), ALL CAPS HUD | era convention; crisp at 1:1 pixels |
| Animation | 2-frame loops (banners, water, fire), palette-swap damage flash, dither-dissolve transitions, screen-shake on siege hits | cheap, period-correct life |
| Optional | CRT scanline overlay toggle (off by default) | modern nicety, never distorts pixels |

Production pipeline: procedural drawing code **plus** a hand-pixel path —
`tools/sprite2rs.ts` converts authored PNGs → palette-quantized Rust byte
arrays; `tools/shot.ts` (Playwright) screenshots every screen for visual
diffing against approved baselines. Graphics QA is part of CI-adjacent dev
workflow (screenshot per scene, pixel-diff vs baseline).

## 3. Audio bible (entry with motivating music — requirement c)

**Amiga sound = ProTracker modules.** Decisions verified by research:

- Playback: **own ProTracker player** (`src/engine/audio/modplayer.rs`,
  dependency-free Rust) renders PCM → WebAudio via AudioWorklet (fallback:
  ScriptProcessor). 4 channels, 8-bit sample warmth, vibrato/arpeggio/
  portamento/set-volume effects — the real deal, not "chiptune-ish".
  (Original plan `xmrs` 0.15 was rejected 2026-11-14: it is a module
  *model/import* library with manual mixer plumbing, not a turnkey
  renderer; the §3 fallback is the boring-better path.)
- Composition: **`tools/compose.ts`** — our own tiny tracker DSL in Bun:
  synthesize 8-bit samples (square 50%/25% pulse, noise, envelopes: kick,
  snare, hat, pluck bass, lead) + pattern tables → real `.MOD` (ProTracker
  M.K.) files in `assets/music/`. I compose; nothing is copied.

**Track plan (v1):**

| Track | Mood / structure |
|---|---|
| `title.mod` — "THE CROWN ENDURES" | the hook, ~75 s overture then seamless loop: 8-bar brass **fanfare** (square lead over pulse triads) → heroic Dorian **march** with a singable lead melody over galloping bass → lyrical bridge → reprise + drums + arpeggio sparkle. Must make you want to draw a sword. |
| `saxon.mod` | warm major castle theme, harp-style arpeggios |
| `norman.mod` | brooding minor invasion march (Norman moves, alarms) |
| `battle.mod` | driving 6/8 combat cue during battle reports |
| `minigame.mod` | playful tavern-reel loop for games |

~25 SFX synthesized live in WebAudio (sword clinks, bow twangs, coin, crowd,
hooves, catapult creak/boom, fanfare blips). Autoplay rules: audio starts on
the first click/key ("PRESS TO BEGIN" herald); mute toggle persists.
Verification: headless Chromium with `--autoplay-policy=no-user-gesture-required`
+ AnalyserNode RMS > threshold ⇒ music-audible test in CI-adjacent script.

## 4. Entry sequence (requirement c, concrete)

1. Black screen → pixel herald banner unfurls (24 frames), text "PRESS ANY KEY
   — SOUND ON". First input unlocks audio, fanfare begins.
2. Title card: animated crown + crossed banners, flame-licked border,
   game name in big bitmap caps; overture continues into A-section loop.
3. Menu (keyboard + mouse): **BEGIN CAMPAIGN** → difficulty (EASY/NORMAL/HARD)
   → intro crawl; HALL OF FAME; HOW TO PLAY ( illustrated pixel pages);
   SOUND ON/OFF.
4. "Your story begins…" dither-dissolve into the campaign map, `saxon.mod`
   up, turn 1.

## 5. Campaign design (requirement d)

### 5.1 Map — England, castle by castle

12 named castles, fixed road network (adjacency graph), laid out geographically
on the pixel map with coastline, forest and hills shading:

- **Saxon:** BUCKINGHAM✦(capital), Oxford, Wallingford, Winchester, Salisbury, Devizes
- **Norman:** LONDON✦(capital), Colchester, Norwich, York, Lincoln, Dover

Fronts: Buckingham–London, Buckingham–Lincoln, Oxford–Lincoln. Dover is a
Norman reinforcement port (choke). Full adjacency table lives in
`campaign-core` with a test that the graph is symmetric and connected.

### 5.2 Kingdom bars (DoC-authentic, from the original's own 4 stats)

| Stat | Meaning |
|---|---|
| **RICHES** | gold; income = Σ castle income × loyalty factor |
| **PROVISIONS** | your army eats 1/turn from a stock (cap 10×castles); shortfall ⇒ desertion + morale loss — armies you can't feed melt |
| **LOYALTY** | 0–100; income multiplier; drops with defeats/heavy upkeep; at 0 castles REVOLT to neutrality each turn |
| **POPULARITY** | 0–100; cheaper recruits, better minigame rewards, luckier events; rises with wins and minigame gold |

### 5.3 Military

- Unit types (5): LEVY 10g / BOWMAN 20g / KNIGHT 45g / CATAPULT 60g —
  as drafted — plus **CHAMPION**: max 3 per side, recruited only via
  minigame triple-wins (see 5.5); garrisoned army fights +25%, enables
  heroic duel moment in battle reports.
- March: one march per castle per turn along roads; full garrison moves.
- Battles: round-based sim — walls absorb (catapults ×3, others half),
  defenders shoot from battlements, 30-round repel limit; walls repair on
  turn end; deterministic seeded RNG. Champion bonus applies; a champion in
  a *losing* defence has a 25% chance to turn the day ("duel" flavor line).
- FOG: enemy garrison counts show as "SEEN: ~N" (±50%) unless scouted.
  **SPY action** (15g): 70% exact reveal of castle + neighbors; failure =
  gold lost (repeatable). Spies also (10%) reveal next-turn event early.

### 5.4 Events (each turn, weighted; both sides suffer equally)

TOURNAMENT HERALD (castle banner → free named minigame, big rewards) ·
MERCHANT CARAVAN (+gold) · BAD HARVEST (−provisions) · PLAGUE (2-turn
income) · KING'S LEVY (+3 levies to capital) · DESERTERS (−2 from largest
army) · from turn 12: **DANISH RAIDERS** strike a weak coast castle (Dover/
London/Wallingford axis) unless garrison ≥10 — neutral pressure, big loot if
repelled.

### 5.5 Minigame economy (motivation loop, requirement e)

- **SPORTS** button in any owned castle (10g): plays one random unlocked
  game; score → BRONZE/SILVER/GOLD reward tier: gold (20–80g), troops,
  provisions, +loyalty/popularity.
- **Event tournaments** (free, from TOURNAMENT HERALD): named featured game,
  2× rewards, and a **triple-gold across three different events ⇒ recruit a
  CHAMPION**.
- HALL OF FAME: per-game best scores in localStorage; title screen shows
  your records — the "see all 13 games" pull.
- Unlock pacing: games 1–4 from start; 5–9 from turn 5; 10–12 from turn 10;
  **DRAGON'S HOARD** appears once, turn ≥ 20 (rare event banner).

### 5.6 Victory / defeat

- **VICTORY:** hold all 12, or be crowned: hold LONDON + ≥8 castles at a turn
  roll (coronation sequence).
- **DEFEAT:** zero castles. Losing Buckingham is not instant loss — it costs
  −30 loyalty and a despair event (modern mercy, keeps games alive).
- Chronicle judgment at turn 90 and every tenth turn after: more castles
  wins ("THE CHRONICLE DECIDES"). An even tale at 90 spares the war; a
  later even tale is broken by London — the prize of the crown decideth,
  so no war draggeth on without an ending.
- Difficulty (title pick): AI attack-ratio, recruit budget, spy frequency.

## 10. Code style

Pure cores (`campaign`, `engine` math, minigame logic) have zero `web-sys`
imports and are deterministic under injected `Xor` RNG; adapters are thin.
Actions return `Result<(), String>` with ALL-CAPS UI text. 4-space, no
`unsafe`, no `.unwrap()` outside init.

```rust
pub trait Minigame {
    fn id(&self) -> &'static str;
    fn tick(&mut self, dt: f32, input: &Input, fb: &mut Framebuffer);
    fn score(&self) -> u32;            // tier thresholds are pure data
    fn state(&self) -> MgState;        // Running | Won(tier) | Lost
}
```

## 11. Testing strategy

- `cargo test` (docker): campaign rules (map integrity, economy, marches,
  fog/spy, events determinism), combat physics (walls favor defender,
  catapults breach, repel, champion bonus, same seed ⇒ same battle), AI
  (beats idle ≤100 turns; AI-vs-AI terminates ≤400; difficulty monotonic),
  each minigame's pure logic (scoring, timers, spawn patterns), MOD encode
  round-trip (`compose.ts` output parsed + rendered by `modplayer`, pitch
  verified ±4 %),
  kingdom-bar clamp invariants (provision starvation deserts, revolt at 0).
- `tools/shot.ts`: every scene screenshot; pixel-diff vs baselines (drift =
  fail); console-error count must be 0.
- Audio proof script: headless chromium (autoplay off switch), click, sample
  AnalyserNode RMS > 0 during title loop.
- Manual: full playthrough smoke per release cut.

## 12. Boundaries

- **Always:** tests before commit; deterministic seeds; update SPEC/module
  specs when rules change; regenerate assets via tools only.
- **Ask first:** new dependencies; CI changes; scope changes; renaming
  module ids; publishing/deploying anywhere.
- **Never:** copyrighted art/music/fonts/names of the original game's
  characters (Berengard, the Black Heather etc.); committed `web/pkg/`,
  `target/`, binaries from outside tools; secrets/tokens; pushing red CI.

## 13. Success criteria (acceptance)

1. `cargo test` green (all groups §11) + clippy `-D warnings` clean.
2. `./build.sh` ≤ 2 MB total payload (wasm + embedded mods) — budget sized
   for 6 embedded MOD tracks.
3. Playwright: title → menu → campaign → minigame → results → end-turn
   screenshots pixel-diff clean; **zero console errors**; audio RMS audible.
4. Entry (c): a first-time visitor hears the fanfare+overture within 2
   seconds of the first click and can start a campaign in ≤3 more.
5. Campaign (d): full loop with fog/spies/kingdom bars/events/AI/victory
   conditions playable; AI on HARD wins ≥8 of 10 self-play games vs EASY
   player policy (measured by sim tests).
6. Minigames (e): all 13 reachable in a campaign, each completable, reward
   tiers functional, HALL OF FAME persists.
7. README documents controls; LICENSE (pending §14.1); CI green on main.
